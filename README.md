# Personal Portfolio Website

This project is my personal portfolio website! I built it from scratch using HTML, CSS, and JavaScript. The website is an overview of my background, education, work experience, and projects, with a focus on data analytics and business.

### Features
- **About Me:** A short introduction and overview of my background and interests.
- **Experience:** An overview of my previous work experience and responsibilities.
- **Projects:** A collection of data analytics and other projects, including their goals, tools, and key results.
- **Education:** My academic background and relevant coursework.
- **Education:** Contacts section.
